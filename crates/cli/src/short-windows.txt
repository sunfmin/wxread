wxread reads WeChat for Windows 4.x directly. Each command prints one JSON
object; a failure is {"error": "…"}, non-zero, naming its fix.
Usage: wxread [--data-dir <dir>] [--keys <file>] <command>
Commands:
  articles  official accounts' articles, newest first; one account's alone
  avatar    write a contact's avatar, as the image it is (--out)
  chats     the account's chats, newest first; --query, --with find one
  contact   one contact in full, by its id
  contacts  the account's contacts by id; --query finds one
  doctor    run first: find WeChat's accounts and the keys; name each fix
  favorites what the account saved (收藏), each as its kind
  file      file get <id>: write a message's, note's, favorite's or Moment's file
  group     a group's notice, owner, members
  messages  a chat's messages, each as its kind, a page at a time
  moments   the Moments WeChat loaded: text, media, likes, comments
  search    find messages across every chat, newest first
  voice     a voice message written as a file that plays; WeChat's 转文字
Options:
  --data-dir <dir>   WeChat's xwechat_files (or WXREAD_DATA_DIR)
  --keys <file>      the keys of the account's databases (or WXREAD_KEYS)
  -h, --help         this screen; --help the guide; --version the version
  <command> --help   what a command reads and answers
