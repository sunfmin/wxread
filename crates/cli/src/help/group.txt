wxread group: one group of the account, with its notice, its owner and
every member, each named as the group shows them.

WHEN TO RUN IT
  To see who is in a group, what its notice (群公告) says, and what each
  member is called there. Run by you or an agent, once the keys are
  supplied; it changes nothing.

WHAT IT READS
  The account's contact/contact.db under its db_storage, with the WAL
  beside it (what WeChat wrote last), with its key: the file --keys
  names, else the contents of WXREAD_KEYS. It is decrypted into memory
  and read there. It writes nothing, anywhere: no decrypted byte reaches
  the disk.

USAGE
  wxread group <id> [--account <id>]

  <id>              the group's id, <n>@chatroom, as `wxread contacts`
                    answers it
  --account <id>    the account to read, as `wxread doctor` names it;
                    with only one logged in, that one

WHAT IT ANSWERS
    account   the account read: its directory's name, as doctor's id
    group     {id, display_name, name, remark, owner, notice, members}:
              id            the id asked for
              display_name  as WeChat shows it: the account's remark,
                            else its name; a group with neither is
                            named as WeChat names it, by its members'
                            display names, the account's left out, in
                            the order WeChat lists them, joined by "、"
                            (e.g. "孙凤君、秦俊斌"); "" for none
              name          its own name; "" for none: a group with no
                            name of its own answers "" here and its
                            members' names in display_name
              remark        what the account calls it; null for none
              owner         {id, display_name}: who owns it; null when
                            WeChat does not say
              notice        {text, by, at}: its notice; null for none
                text          what it says
                by            {id, display_name}: who posted it; null
                              when WeChat does not say
                at            when, RFC 3339 in UTC; null when WeChat
                              does not say
              members       [{id, display_name, name, name_in_group,
                            remark}], by id, the account among them:
                id            their id, a wxid
                display_name  as the group shows them: the account's
                              remark for them, else their name in the
                              group, else their name; "" for none
                name          what they call themselves; "" when the
                              account has no contact of them
                name_in_group the name they set in this group; null for
                              none
                remark        what the account calls them; null for none

TRIPS YOU UP
  - An unknown id is an error whose fix is `wxread contacts --query`; an
    id that is not a group's is an error whose fix is `wxread contact`.
  - A member the account met only in this group is a member still, with
    a name of "" when WeChat keeps no contact of them.
  - A group WeChat keeps no record of (one the account left) answers no
    owner and no members.
  - Its key missing, or no longer opening its database, is an error
    naming contact/contact.db; its fix is `sudo wxread keys`, then
    supplying the keys again.
