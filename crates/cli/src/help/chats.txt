wxread chats: the account's chats, newest first, a page at a time; with
--query, only the chats whose name holds a text; with --with, only the
chats that hold the contacts given, the smallest first.

WHEN TO RUN IT
  To see which chats there are and pick one, before reading its messages.
  To find a chat by its name without paging every one:
    wxread chats --query <name>
  To find the chat with someone, or the group of you, A and B:
    wxread chats --with <A's id> --with <B's id>
  To find the groups that are only ads, to suggest to the account's owner
  which to leave: a group whose recent.from_top_sender is nearly all of
  its recent.messages, and whose account_spoke is false. Read a few of
  its messages (`wxread messages --chat <id>`) before suggesting it;
  only the owner decides, and `wxread group leave` leaves them.
  `wxread contacts --query <name>` finds each one's id.
  Run by you or an agent, once the keys are supplied; it changes nothing.

WHAT IT READS
  The account's session/session.db and contact/contact.db under its
  db_storage, and, when the page holds a group, its message databases
  (message/message_<n>.db), each with the WAL beside it (what WeChat
  wrote last), with their keys: the file --keys names, else the contents of WXREAD_KEYS.
  Each is decrypted into memory and read there, after its key is checked
  against its first page. It writes nothing, anywhere: no decrypted byte
  reaches the disk.

OPTIONS
  --account <id>    the account to read, as `wxread doctor` names it;
                    with only one logged in, that one
  --with <id>       only the chats that hold this contact (a person or an
                    official account, by id); again for each one more, and
                    a chat must hold them all. With one, the direct chat
                    with them first; then every group they are all members
                    of, the smallest first, newest first among the same
                    size, whether or not the group has a chat in the list
  --query <text>    only the chats whose id, display_name (as answered: the
                    remark first, and an unnamed group's members' names)
                    or own name (what a contact or group calls itself,
                    remarked or not) holds it, whatever its case; with
                    --with, only those of its chats
  --limit <n>       how many chats a page holds, 1 to 1000; 100 unless given
  --cursor <next>   start after the page that answered this `next`, asked
                    with the same --query and --with

WHAT IT ANSWERS
    account   the account read: its directory's name, as doctor's id
    chats     [{id, display_name, kind, read_with, last_message_at, unread,
              members, recent, account_spoke}], newest first (with
              --with, the smallest first):
              id               its contact's id: a wxid, or a group's
                               <n>@chatroom; a folder's id in WeChat's
                               list (see kind)
              display_name     as WeChat shows the chat: the account's
                               remark for it, else its own name; a group
                               with neither is named as WeChat names it,
                               by its members' display names, the
                               account's left out, in the order WeChat
                               lists them, joined by "、" (e.g.
                               "孙凤君、秦俊斌"); "" when the account has
                               no contact of it; a folder by WeChat's
                               name for it
              kind             "direct" (with one contact), "group", or
                               "folder": an entry of WeChat's list that
                               holds others and has no messages of its
                               own, one of
                               @placeholder_foldgroup     "折叠的群聊",
                                 the groups folded away, each listed
                                 here as a group of its own
                               brandsessionholder         "订阅号消息",
                                 what subscription accounts sent
                               brandservicesessionholder  "服务号",
                                 the service accounts
              read_with        the command that reads what it holds:
                               "wxread messages --chat <id>" for a direct
                               chat or a group; for a folder,
                               "wxread chats" (the folded groups) or
                               "wxread articles" (official accounts')
              last_message_at  when its last message was, RFC 3339 in UTC;
                               null for none
              unread           its messages not yet read
              members          how many are in it, the account included:
                               2 for a direct chat; null for a group
                               WeChat keeps no record of the members of,
                               and for a folder
              recent           of a group, who sent the most of its 50
                               newest messages this Mac holds:
                               {messages, top_sender, from_top_sender}:
                               messages, how many of the 50 name their
                               sender (a system message names none);
                               top_sender, who sent the most of those,
                               {id, display_name} (of two who sent as
                               many, the one who sent the newer);
                               from_top_sender, how many they sent.
                               null for a group with no such message,
                               a direct chat and a folder
              account_spoke    of a group, whether the account sent any
                               of its messages this Mac holds: true or
                               false; null for a direct chat and a
                               folder
    next      pass it as --cursor for the next page; null on the last one

TRIPS YOU UP
  - Paging is by where each chat was when the page was read: a chat with
    a new message since moves to the front, so it is not on a later page,
    and a fresh run from the newest shows it.
  - An official account (gh_...) is a "direct" chat.
  - A folder is no chat: `wxread messages --chat <folder>` is an error
    naming its read_with.
  - A --query is matched against each chat's text as it is; it does not
    match pinyin. A member's name finds the direct chat with them and
    every unnamed group named by them, not a group with a name of its own
    that they are in: --with <their id> finds those.
  - --with takes ids, not names: an id that is no contact is an error
    naming `wxread contacts --query`, and a group's id is an error naming
    `wxread group <id>`, which answers its members.
  - A group --with answers that has no chat in the list (it was deleted
    from WeChat's list, or never had a message) has last_message_at null
    and unread 0; `wxread messages --chat <id>` reads what it holds.
  - recent and account_spoke count only what WeChat on this Mac holds:
    a group whose messages were never synced to it has recent null and
    account_spoke false, whatever was said in it elsewhere.
  - The keys must open every database it reads. One missing, or one that no longer
    opens its database (WeChat created its databases again: logging out
    and in, some updates), is an error naming the database; its fix is
    `sudo wxread keys`, then supplying the keys again.
  - Several accounts logged in is an error naming them: pass --account.
