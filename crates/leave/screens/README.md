# Screens of WeChat's window, as their text

Each file is one screen of WeChat for Mac 4.1.15's window, kept as what
`wxread group leave` reads of it: the window's size (`window`), the frame of
a confirmation's own window when one is up (`dialog`), then one line per
text macOS recognizes, where it is, in the window's points from its top
left. They are written from the screens docs/leave-group.md records on
`wxread 退群测试` (the labels, their order, the regions they are read in),
and from what went wrong there (a paste that did not land, a name wrapped
onto two lines, the chat list's timestamps behind the confirmation). No
screenshot is kept, and none of the owner's chats: the `-other` screens are
the ones a run must stop on.
